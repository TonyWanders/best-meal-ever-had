## The entry

> My grandmother's ofe nsala in Nnewi fogged my glasses with pepper steam, the catfish falling apart on my tongue while rain drummed the zinc roof and nobody at the table said a word.

## How it works

`main.py` is deterministic: it writes the sentence above to `/output/entry.txt`
every run, with no randomness, no network and no input files.

Run it:

```sh
python3 main.py
```

Then check `/output/entry.txt` (181 characters, one sentence).
